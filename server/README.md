# Switch 云存档 · 服务端

自托管的备份服务端，配套根目录的 Switch 客户端（`.nro`）。**只用 Python 标准库**，不需要 pip 安装任何依赖。

- `GET /api/v1/*`：客户端协议（与 `docs/API.md` 一致）
- 首次运行向导：显示 API 地址 + 令牌，自动检测客户端是否连上，然后创建管理员
- 管理后台：设备、存档（含历史版本下载）、相册（图片/视频预览）、游玩时长、详细游玩事件
- SQLite 索引 + 文件存储，数据都在 `server/data/`

## 运行

```bash
python server/switchcloud_server.py --host 0.0.0.0 --port 8420
```

Windows 也可以直接双击 `server/start.bat`。

启动后打开：

```
http://127.0.0.1:8420/
```

如果通过 `127.0.0.1` 打开，向导会提醒你改用局域网地址（例如 `http://192.168.1.10:8420`），Switch 才能访问。

## 首次使用流程

1. 打开管理页面，会进入「初次设置」
2. 把页面上的 **服务器地址** 和 **访问令牌** 填进 Switch 应用（设置 → 保存）
   - 令牌默认是 8 位（形如 `K7M2-9QX4`），**不区分大小写，横线可以省略**
   - 也可以用 `--token-length 24` 或 `--token 自定义值` 改成更长的
3. 在 Switch 上点一次「测试服务器连接」或上传任意数据
4. 页面的状态会变成「已检测到客户端」，管理员表单解锁
5. 设置用户名 / 密码 → 自动登录进入管理后台

> 如果客户端一直连不上，可以先按向导里的局域网地址在电脑浏览器测试；
> 确认防火墙允许 TCP 8420。

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--host` | 监听地址，默认 `0.0.0.0` |
| `--port` | 端口，默认 `8420` |
| `--data` | 数据目录，默认 `server/data` |
| `--public-url` | 反向代理后的外部地址，例如 `https://cloud.example.com` |
| `--set-admin user:pass` | 应急：直接创建管理员（客户端连不上时） |
| `--reset-token` | 重置 API 令牌（按当前长度重新生成） |
| `--token VALUE` | 直接设置一个自定义令牌 |
| `--token-length N` | 生成令牌的字符数（默认 8；公网建议 24+） |
| `--max-body-gb` | 单次上传上限，默认 4 GB |

## 数据目录

```
server/data/
├── cloud.db              # SQLite：设备、存档索引、相册索引、时长、事件
├── INFO.txt              # 启动时写入的对接地址和令牌（含令牌，注意权限）
├── server.log
├── saves/<device>/<title>/<user>/latest.zip
│                              └── history/<timestamp>.zip
├── album/<device>/<年>/<月>/<日>/<文件>
└── playlog/<device>.json
```

备份 `server/data/` 就等于备份全部云端数据。

## 安全说明

- 默认是 HTTP，适合家庭局域网。**公网部署请放在 HTTPS 反向代理后面**，并把
  `--public-url` 设置为外部地址（向导会显示它）。
- 访问令牌等价于客户端密码；管理页可以随时重置。默认 8 位（约 40 bit）是为了方便
  在 Switch 上输入，仅建议在家庭局域网使用；公网部署请用 `--token-length 24` 或更长。
- 令牌校验不区分大小写、允许省略横线；连续 30 次鉴权失败会临时限流。
- 管理员密码使用 PBKDF2-SHA256（200k 次）保存，会话是 HttpOnly Cookie。
- 相册路径会做穿越校验；所有数据库路径都会验证在数据目录内。
- 目前只有单个全局客户端令牌（客户端协议限制），令牌重置后需要更新 Switch 配置。
- 每次启动会复用同一个服务器实例 ID；如果 `server/data/cloud.db` 被删除重建，
  客户端会在下次上传时检测到变化并自动完整上传一次。

## 客户端的兼容性

客户端只依赖 `docs/API.md` 里的端点。服务端另外实现了一个 `GET /api/v1/playlog`
方便调试，客户端不使用。
